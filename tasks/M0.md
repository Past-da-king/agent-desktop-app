# M0: Scaffold

Goal: an empty but real project that builds, tests, boots in Electron, and renders a React page in a plain browser.

## Build this
1. Root `package.json`: `"private": true`, `"workspaces": ["packages/*", "apps/*"]`, `"type": "module"`, engines node >= 22.13.
   Scripts: `typecheck` (runs tsc --noEmit in every workspace), `build` (builds core then the desktop app), `test` (vitest run at root),
   `dev` (electron-vite dev in apps/desktop), `dev:web` (Vite dev server for the renderer only, on port 5173, mock bridge), `shoot` (`node scripts/shoot.mjs`).
2. `tsconfig.base.json`: strict, ES2022, moduleResolution Bundler, `noUncheckedIndexedAccess` true, `exactOptionalPropertyTypes` false.
3. `packages/core` named `@agent/core`: `src/index.ts` re-exports `./ipc`. Build with `tsc` to `dist/` is NOT needed; consumers import the
   TypeScript source through a `paths`/`exports` entry pointing at `src/index.ts` (keep it simple: `"main": "src/index.ts"`, `"types": "src/index.ts"`;
   Vite and vitest handle TS). Add one trivial test `test/ipc.test.ts` that checks `DEFAULT_SETTINGS.shell === 'ask'`.
4. `apps/desktop`: electron-vite project (main, preload, renderer). Dependencies: electron (latest stable, major >= 38), electron-vite, vite,
   react 18, react-dom 18, zustand, @types/react, @types/react-dom, typescript. Dev: vitest.
   - Main: `src/main/index.ts` creates a frameless `BrowserWindow` 1280x820 (min 360x600), `titleBarStyle` hidden-compatible frameless
     (`frame: false`), `show: false` then `ready-to-show`; secure webPreferences from PLAN.md section 7; loads the renderer (dev URL or built file);
     `app.requestSingleInstanceLock()`; quits on all windows closed except macOS. A `--smoke` CLI flag makes it load, wait for the renderer to
     report `window.agent` exists, print `SMOKE OK` and `app.exit(0)` (exit 1 with a message on failure/timeout of 20 s).
   - Preload: `src/preload/index.ts` exposes a minimal `window.agent` with `platform`, `version` and the `window` group
     (`minimize`, `toggleMaximize`, `close`, `isMaximized`, `onMaximizeChange`) over IPC; the other groups are stubbed to reject with "not implemented yet" (later milestones fill them in).
   - Renderer: `src/renderer/index.html` (with the CSP from PLAN.md), `main.tsx`, `App.tsx` showing the text "Agent" in a centered element
     styled with a CSS variable, `bridge/index.ts` exporting `agent` (= `window.agent` if present, else `mockAgent`), `bridge/mock.ts` a minimal
     `AgentApi` implementation (platform 'web', in-memory settings, everything else resolves to empty values or no-ops; later milestones grow it).
5. `scripts/` ALREADY EXISTS (gate.sh, shoot.mjs, fake-sync-server.mjs, lint-checks.mjs, count-tests.mjs, run-milestones.sh). Do not edit them.
   `shoot.mjs` serves the BUILT renderer from `apps/desktop/out/renderer/index.html`, so `npm run build` must produce exactly that path
   (electron-vite's default `out/renderer`) with relative asset URLs (`base: './'`) so it also works from a plain static server.
   Add `playwright-core` as a root devDependency (library only; do NOT download browsers; Chromium is already on this machine).
6. `apps/desktop/package.json` must have `"main": "out/main/index.js"` so `npx electron .` in that folder starts the built app.
   `npm run dev:web` = a plain Vite dev server for the renderer only (config `apps/desktop/vite.web.config.ts`, root `src/renderer`, port 5173).
7. `.gitignore` ALREADY EXISTS; keep it. Add `README.md` (how to run: dev, dev:web, test, shoot, gate; 15 lines).
8. The boot page (`#/`) must render without console errors on the mock bridge (fresh install mode) at 1440 light and dark and 390 light.

## Gate (`bash scripts/gate.sh M0`) checks
typecheck, build, `npm test`, `node scripts/shoot.mjs --only boot` (renders `#/` at 1440 light and dark and saves PNGs), Electron smoke (best effort).
