# M8: Desktop-native

Goal: the things that make it feel like a real desktop app, and the first tools that touch this computer.

Read first: PLAN.md sections 5.3, 7; `reference/phone/tools/{FileTools,CodeTools}.kt` for tool semantics.

## Build this
- Window: frameless with working controls (done in M3/M4); remembers size/position/maximized; minimum size; double-click title bar toggles maximize; Windows snap-friendly (no custom resize that breaks it).
- Tray (`tray.ts`): icon (use a generated PNG from the mascot, 16/32px; build it with a small canvas-free approach: ship static PNGs in `apps/desktop/resources/`), menu: Open Agent, Quick Ask, "Needs you (n)" when waiting, Pause routines (toggle), Quit.
  `closeToTray` setting: closing the window hides it, routines keep running; Quit really quits. First time it hides, show a notification "Agent is still running in the tray".
- Global hotkey (`hotkey.ts`): `globalShortcut.register(settings.quickAskHotkey)` opens/focuses a small always-on-top Quick Ask window (frameless, 640x180, centered, closes on blur and Esc) that sends the typed text to the Runner and shows the answer inline (renderer route `#/quick-window`). Registration failure shows a message in Settings. Re-register when the setting changes.
- Launch at login (`app.setLoginItemSettings`) from the setting; single instance lock focuses the existing window.
- Drag and drop: dropping files anywhere on the Chat view shows a full-sheet drop target ("Drop to attach"), attaches via `files.pathsFor`; images are shown as thumbnails and sent to the model as image blocks; other files are referenced by path in the prompt. 20 MB cap with a friendly message.
- Tools (`tools/files.ts`): `files_list(path)`, `files_read(path, maxChars?)`, `files_write(path, content)` (approval unless inside a granted folder), `files_find(root, pattern)`, `files_pick()` (opens the OS picker, result is the chosen paths), `files_move`. Path rules from PLAN 7: resolve + realpath; deny outside granted folders/user picks unless approved; never follow symlinks out of a granted folder.
- `tools/shell.ts`: `shell_run(command, cwd?, timeoutSec?)`: ALWAYS `ctx.approve` with the exact command shown, unless `settings.shell === 'never'` (then refuse). Runs via `child_process.spawn` with the platform shell, 60 s default timeout (max 600), output capped at 20000 chars, kills the process tree on abort. Never inherits the API key or sync token in env (strip names matching /KEY|TOKEN|SECRET|PASSWORD/i).
- `tools/code.ts`: `run_code(language: 'javascript'|'python', code)` in a temp directory child process (node / python3 if found), approval first time per run, 30 s timeout, returns stdout/stderr and lists files it created (paths).
- Settings > "This computer" section real: granted folders (add via picker/remove), shell mode, launch at login, close to tray, hotkey recorder (press the keys), notifications. Connections > "This computer" card real.
- `Machines` in Connections: one entry "This computer" with OS/arch/hostname, granted folders count; others "Coming soon".
