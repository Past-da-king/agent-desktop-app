# M11: Packaging

Goal: installers can be built with one command per platform.

## Build this
- `apps/desktop/electron-builder.yml`: appId `app.agent.desktop` (placeholder, documented), productName `Agent`, Windows: NSIS (per-user install, no admin) + portable; macOS: dmg + zip (hardened runtime flags present, signing/notarisation read from env, not required);
  Linux: AppImage + deb. `asar` on, only needed files, no source maps in release. Icons: generate `build/icon.png` (1024), `icon.ico`, `icon.icns` from a mascot SVG with a script (`scripts/make-icons.mjs` using only Node + the Chromium already on the machine via Playwright to rasterise; if `.icns/.ico` packing is not possible without extra deps, produce the PNG set and document the one-line command electron-builder runs to convert).
- npm scripts: `dist:win`, `dist:mac`, `dist:linux`, `pack` (unpacked dir for smoke tests).
- Auto update: wire `electron-updater` ONLY IF it is trivial; otherwise leave an `updates.ts` stub that reads a `AGENT_UPDATE_URL` env (no default) and does nothing when empty. No hardcoded update server.
- App identity: single `APP_NAME` constant; window title, tray tooltip, notifications all use it; "About" dialog in Settings (version, licences link, "Open logs folder").
- Logging: `electron-log` or a 40-line file logger to `userData/logs/main.log` with rotation; NEVER logs keys, tokens, prompts or file contents; unit test that redaction removes `sk-...`, Bearer tokens and emails.
- Crash safety: `process.on('uncaughtException')` logs and shows a calm dialog; renderer crash reloads once.
- README: build and release steps, including how Windows is built on the Windows machine (`ssh pc2`): the exact commands.

## Gate
`bash scripts/gate.sh M11`: typecheck, build, tests, `npm run pack` succeeds (Linux unpacked build), redaction test passes.
