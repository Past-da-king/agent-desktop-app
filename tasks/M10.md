# M10: Helpers

Goal: the main agent can delegate work to parallel helper agents, steer and stop them, and the chat shows them.

Read first: `reference/phone/AgentRuntime.kt` (startHelper, runHelper, steerHelper, pushHelper, stopHelper, deliver, helpersReport, the MAIN prompt's YOUR JOB / YOUR HELPERS parts),
`reference/phone/tools/AgentTools.kt`, `reference/phone/Branching.kt` (read only; branching is NOT in scope).

## Build this
- `runtime/helpers.ts`: `HelperManager` starting helper runs as their own `AgentLoop` with `thread = helper id`, the HELPER system prompt (port from the Kotlin's HELPER role: do the job fully, reply with ONLY the result), the full worker toolset (everything except delegate/helper_* and routine/skill creation by main), turn rows persisted per thread, an incoming steer inbox, `ctx.agentLabel` = helper label, state `working|done|failed|stopped`, max 4 concurrent (rest queue).
  Results come back to the main agent as a new main turn: `[Helper #id "label" finished]\n<result>` (port the `gaveUp` nudge: if the result matches the give-up regex and pushes < 2, append the nudge to use `helper_push`).
- Tools for the MAIN agent: `delegate(tasks:[{label, brief, model?}], together?)`, `helper_steer(id, message)`, `helper_push(id, message)`, `helpers_status()`, `helper_stop(id)`. MAIN also gets a 5-action-step budget per turn for worker tools (port `Budgeted`); MAIN never gets browser/file/shell tools directly beyond the budgeted wrappers. Update the MAIN prompt with YOUR JOB / YOUR HELPERS (single roster = the user's chosen model; multi-model rosters are NOT in v1).
- Chat: helper rows (`kind: 'helper'`, meta `{id,label,state,summary}`) render as compact cards with live state, expandable to see the helper's activity, Stop button; hidden once finished (the result is in the main reply), as on the phone.
- Home "Right now" lists working helpers. Palette gets "Stop all helpers".
- Mock bridge: helper cards in the demo thread.

## Tests
`helpers.test.ts` with the fake AI server: delegate -> helper runs -> result delivered as main turn; two helpers in parallel; steer reaches the helper before its next step; stop; queue beyond 4; give-up nudge; main budget exceeded message.
