# M11 report: Packaging

## What was built

- `apps/desktop/electron-builder.yml` with the documented placeholder `appId: app.agent.desktop` and
  `productName: Agent`. Windows (NSIS per-user with `allowElevation: false`, plus portable), macOS
  (dmg + zip for x64/arm64, hardened runtime on, entitlements file, signing/notarisation left to
  environment variables), Linux (AppImage + deb). `asar` on, files limited to `out/**/*` and
  `package.json`, source maps excluded.
- `npm run pack`, `dist:win`, `dist:mac`, `dist:linux` in both the desktop package and the root.
- `scripts/make-icons.mjs`: draws the scout mascot from `design/mockup.html` as SVG, rasterises it in
  the installed Playwright Chromium, and writes `build/icon.png` (1024), `build/icon.ico` and
  `build/icon.icns` plus a PNG set. ICO and ICNS containers are generated in the script, so no extra
  image dependency was added.
- `app-info.ts`: one `APP_NAME` constant feeding the window title, tray tooltip and notification
  title (the tray and notifications land in M8/M7; the helpers are ready). The window title is
  enforced through `page-title-updated`.
- `logger.ts`: a small rotating file logger at `userData/logs/main.log`, one previous file at 1 MB.
  `redact()` removes `sk-...`, Google `AIza...` keys, Bearer tokens, labelled passwords/tokens and
  email addresses before writing.
- `updates.ts`: the auto-update stub. It reads `AGENT_UPDATE_URL` only, has no default, and does
  nothing when the value is empty or not http(s). `electron-updater` was not added.
- Crash safety: `uncaughtException` and unhandled rejections are logged. A calm dialog is shown for
  the former (Keep going / Restart). A renderer crash reloads the window once, then shows the same
  calm dialog.
- About dialog (`renderer/ui/AboutDialog.tsx`) showing version, Electron version, platform, a
  licence link and an "Open logs folder" button. The IPC contract gained an additive `app` group and
  the preload, mock bridge and channel list were updated with it.
- README rewritten with build, packaging, signing, icon, log, release and Windows-on-`ssh pc2`
  instructions.

## Changes outside the obvious M11 files

- `packages/core/package.json` now exports `./ipc` and the desktop tsconfig maps it. The renderer's
  mock bridge imports `DEFAULT_SETTINGS` from that file. Without this, the renderer bundle dragged
  in `model.ts` and its `node:fs` import and the build failed. This is additive and does not change
  the wire contract.
- `electron` and the build-only packages moved to `devDependencies`. `electron-builder` refuses to
  package when `electron` is a runtime dependency, and every runtime package here is bundled by
  electron-vite. The packaged asar is about 302 KB and contains only `out/` and `package.json`.
- `scripts/make-icons.mjs` is new under `scripts/`. It is the file M11 names and it does not touch the
  gate or any existing script.

## What I could not finish / verify

- No Windows installer or macOS package was produced here: those commands need their own platforms.
  Only the Linux unpacked `pack` and the Electron smoke boot were run.
- Code signing and notarisation are configured but not exercised (no certificates here), as the
  milestone allows.
- The base worktree is M3, so there was no Settings view to put the About dialog inside. The dialog
  is a self-contained component and is currently reachable from the boot screen. M4 should mount
  `AboutDialog` from Settings and remove the temporary boot-screen button.
