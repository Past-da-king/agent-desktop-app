# M2: Core: sync

Goal: `@agent/core/sync` implements the HLC and the sync protocol against the fake sync server.

Read first: `reference/kotlin-shared/sync/*.kt` (Hlc, Change, SyncClient, SyncEngine, SyncStore) and `reference/kotlin-sync-service/Main.kt`
(the server; PLAN.md section 4 summarises). `scripts/fake-sync-server.mjs` is the test server.

## Build this (`packages/core/src/sync/`)
- `hlc.ts`: `HlcStamp {millis, counter, device}`, `encodeStamp`, `decodeStamp`, `compareStamps` (numeric millis, numeric counter, then device string),
  `class Hlc(device, clock = Date.now)` with `now()` and `observe(remote)`, ported EXACTLY (see the Kotlin; the `observe` counter rules matter).
- `change.ts`: `Change {entity, id, deleted, stamp: string, payload: Record<string,unknown>, seq?}`, `EntityName` re-used from `ipc.ts`.
- `store.ts`: the `SyncStore` interface: `deviceId`, `localChanges(afterStamp|null)`, `applyRemote(changes)`, `pushMark()`, `setPushMark`, `cursor()`, `setCursor` (all async).
- `client.ts`: `SyncClient(baseUrl, token, fetchImpl?)` with `push(device, changes) -> cursor`, `pull(since, {wait?, signal?}) -> {changes, cursor}`;
  static `register`, `login`; `SyncException(status, message)` (status 0 = network). Parse server errors `{error:{message}}`.
  Send header `Authorization: Bearer <token>`. Block plain http to non-loopback unless the caller says allowHttp (reuse `http-policy.ts`).
- `engine.ts`: `SyncEngine` ported from the Kotlin with these additions: an `AbortSignal`-aware long-poll loop (`start()` runs
  push-then-pull(wait=25) repeatedly; on error back off 2 s, 4 s, ... max 60 s), `nudge()` (debounced 300 ms push after a local write),
  an event emitter for status (`signedIn, syncing, lastSyncedAt, error, pendingPush`) and `onApplied(changes)` callback, a mutex so passes never overlap,
  `syncOnce()` for the onboarding step, `stop()`.
- `memory-store.ts`: `MemorySyncStore` a complete in-memory `SyncStore` (rows map, LWW apply) used only by tests and as the reference semantics.

## Tests (`packages/core/test/sync-*.test.ts`)
- HLC: monotonic when wall clock goes backwards; `observe` makes next stamp greater than the remote; tie broken by device; encode/decode round trip incl. device ids containing dashes.
- Client vs fake server: register, duplicate email 409, login 401 on wrong password, push/pull cursor, per-user isolation (user B sees nothing of A), `wait` long-poll returns early when another client pushes and returns empty after timeout (use wait=1).
- Engine: two `MemorySyncStore`s, same account. A creates a row, syncs; B pulls it. Both edit the same row: the later HLC stamp wins on both. A deletes (tombstone), B's stale edit does not resurrect it.
  Offline: server down (close it), local writes accumulate (`pendingPush` > 0), server back up, next pass pushes them. Own-echo is skipped. Cursor persists across engine restarts.
- Long-poll: B's `start()` loop applies A's push within 1.5 s without a timer tick.
