# M9: The agent's browser

Goal: the agent gets its own real browser, visible in the Chat's docked panel, and drives it with tools. The person can take over when a page needs them.

Read first: `reference/phone/tools/BrowserTools.kt` (tool names and semantics), `design/mockup.html` Chat panel (the browser mock with the "Nova is here" pill).

## Build this (`apps/desktop/src/main/browser/`)
- `browser.ts`: `AgentBrowser` managing a `WebContentsView` attached to the main window inside the panel's rectangle (the renderer reports the panel bounds through a new `browser.setBounds({x,y,width,height,visible})` API; hide the view when the panel is closed or the route is not Chat).
  Session partition `persist:agent-browser` (separate from the app UI). Not sandbox-disabled; `contextIsolation` on; no preload; popups open as new tabs in the same view set (max 5 tabs), downloads go to a per-run temp folder and the file is offered to the agent as a path.
- Page access through `webContents.executeJavaScript` in an isolated world and `debugger`-free helpers: `outline()` (a compact numbered list of interactive elements + visible headings + a NOTE line for blockers like captchas), `read(selectorOrIndex)`, `click(index)`, `type(index, text, submit?)`, `press(key)`, `scroll(dy)`, `waitFor(text|selector, timeoutSec)`, `back()`, `screenshot()` (returns an `[[image:/tmp/...png]]` marker so the loop shows it to the model), `upload(index, path)`.
- Tools `browser_open(url)`, `browser_look()`, `browser_read`, `browser_click`, `browser_type`, `browser_press_key`, `browser_scroll`, `browser_wait_for`, `browser_back`, `browser_upload`, `browser_handoff(reason)`, `browser_show_user()`. Spec text copied from the Kotlin tools, adapted to indexes.
  `browser_open` allows only http(s). `browser_handoff` posts an approval-style card "Nova needs you in the browser: <reason>" with a "Done, carry on" button, and gives the person control (the view accepts input; while the agent drives, an overlay badge "Nova is here" shows and input is ignored).
  URL policy: block `file:`, `chrome:`, `devtools:`; block navigating to loopback/private IPs unless the person typed that URL themselves.
- Renderer: Panel shows live state: URL bar (read-only text + "Open in my browser" button), back, reload, tabs strip, the "Nova is here" pill; empty state "The agent's browser opens here when it needs one". Panel is collapsible, remembers its width (draggable splitter, 320-560px).
  The mock bridge keeps showing the SkyHop demo; add `browser` group to `AgentApi` additively.
