# M3: Main process: store, settings, secrets, IPC, account

Goal: the Electron main process owns the data. `window.agent` works for settings, account, data and window controls, over real IPC.

Read first: PLAN.md sections 4 and 7, `packages/core/src/ipc.ts`, `reference/kotlin-shared/store/AgentStore.kt`, `reference/kotlin-shared/data/Settings.kt`.

## Build this (`apps/desktop/src/main/`)
- `db.ts`: `class Store implements SyncStore`, using `node:sqlite` `DatabaseSync`. Constructor `(file: string, clock?)`; creates the tables from PLAN.md 4.1
  (WAL on). Methods: `list(entity)` (non-deleted rows as `{id, ...payload}`, ordered by `createdAt` then stamp),
  `get(entity, id)`, `upsert(entity, input)` (new uuid if no id; fill `createdAt`, `updatedAt` where the type has it; new HLC stamp; returns the row),
  `remove(entity, id)` (tombstone + new stamp), `clearAll()`, `onChange(cb)` event, plus all `SyncStore` methods. `applyRemote` implements the LWW rule
  of PLAN.md 4.3 and emits one change event per entity touched. Keep one HLC per store, seeded with `deviceId` from `kv` (create once).
- `settings.ts`: `SettingsStore(file)` reading/writing `settings.json` (atomic write: temp file then rename), merging over `DEFAULT_SETTINGS`;
  `get()`, `save(patch)` (validates types, ignores unknown keys, clamps strings to 500 chars), `onChange`.
  `deviceName` defaults to `os.hostname()` the first time.
- `secrets.ts`: `Secrets(dir, safeStorage)` with `get(name)`, `set(name, value)`, `delete(name)`, `encryptedAtRest(): boolean`.
  `safeStorage` is passed in (an interface with `isEncryptionAvailable`, `encryptString`, `decryptString`) so tests use a fake. Fallback file mode 0600 when unavailable.
  Names used: `apiKey`, `syncToken`.
- `account.ts`: `AccountService` ties `Store` + `SettingsStore` + `Secrets` + `SyncEngine` (from `@agent/core`): `signIn({serverUrl,email,password,mode})`
  (validate email shape and password >= 6 before calling; on success save token to secrets, `syncEmail`, `syncUrl`, `signedIn:true`, start the engine),
  `signOut()` (stop engine, delete token; local data stays), `firstSync()` (a pass that reports `SyncProgress` counts per entity from the applied changes),
  `status()`, events. On app start, if a token exists, start the engine.
- `ipc.ts`: `registerIpc({store, settings, secrets, account, window controls})`. One `ipcMain.handle('agent:<group>.<method>', ...)` per `AgentApi` method;
  validate arguments; events are sent with `webContents.send('agent:evt:<name>', payload)` to every window. `chat.*` and `routines.*` and `files.*`
  handlers return "not implemented yet" for now (M6/M7/M8 fill them in).
  `settings.checkKey` makes the tiny completion call using `@agent/core` providers: `{ok:false, message}` with a plain-words message on failure
  (401 -> "That key was not accepted", network -> "Could not reach the provider", others -> the provider's message).
  `settings.providers` returns the catalog. `settings.reset` wipes the DB rows, settings and secrets.
- `preload/index.ts`: full `window.agent` over `ipcRenderer.invoke`, with `onX` subscriptions returning an unsubscribe. Names exactly as `AgentApi`.
  `files.pathsFor` uses `webUtils.getPathForFile`.
- `index.ts`: wires everything with real paths under `app.getPath('userData')`, creates services before the window, window state (size/position) remembered in `window-state.json`.

## Tests (vitest, plain Node, `apps/desktop/test/`)
- `db.test.ts`: upsert/list/remove/tombstones; ordering; two `Store`s synced through `SyncEngine` + the fake sync server converge (reuse `scripts/fake-sync-server.mjs`);
  LWW; `applyRemote` skips own device; payload round trip keeps field names from `ipc.ts`.
- `settings.test.ts`: defaults, merge, invalid input ignored, atomic write survives a crash-simulated leftover temp file.
- `secrets.test.ts`: encrypted path and fallback path, wrong-name delete is a no-op, nothing readable in plain text when encryption is on (fake safeStorage XORs/base64s).
- `account.test.ts`: register against the fake server, wrong password error message, sign out keeps data, restart with saved token resumes sync.
- `ipc-contract.test.ts`: every method name on `AgentApi` (derived from a list in the test) has a registered handler in `registerIpc` (use a fake `ipcMain`).
